# 刃先断面ビューア

包丁の右面・左面の輪郭測定データ（Taylor Hobson 等の X/Z テキスト）を読み込み、刃先をぴったり原点に合わせて断面グラフを作るツールです。

## 使い方

1. `hasaki-danmen.html` をダブルクリックしてブラウザ（Chrome / Edge 推奨）で開く
   - Plotly を埋め込んでいるので、インターネット接続なしで動作します
2. 「研磨前」「研磨後」の各セットの枠に、右面・左面の2ファイル（例: `no14_r50_001.txt`, `no14_l50_002.txt`）をドラッグ＆ドロップ
   - 右面・左面はファイル名の `_r` / `_l` で自動振り分け
   - 「右面」「左面」の小枠へ直接ドロップ・クリックで個別に入れ替え
   - 枠の外に4ファイルまとめてドロップすると、測定日時の古い順に研磨前→研磨後へ振り分け
3. 刃先が自動検出され、先端の上下中点を原点 (0, 0) にした断面（右: 刃先、上: 右面、下: 左面）が重ねて表示されます

## 機能

- **測定セット**: 研磨前・研磨後の枠を用意。「＋ セット追加」で3つ以上（研磨2回目など）も比較可能。セット名・色・線の種類（実線/破線/点線/一点鎖線、既定は研磨前=破線・研磨後=実線）・表示を変更可能
  - ドロップのやり直し: 各ファイル枠の「×」で1ファイルを外す、「空にする」で枠を残したまま両面を外す、「⇅上と入替」で研磨前/研磨後の取り違えを中身ごと入替（名前・色は枠に残る）、「左右入替」で右面/左面を入替
  - 「セット削除」は3つ以上あるときのみ表示
- **先端の厚みを保持**: 右面・左面の測定Z座標の差をそのまま厚みとして使うため、刃付け前の平らな端面の厚さも表示（点線が端面）。旧方式（両面の刃先を1点に合わせる）にも切替可能
- **刃先の自動検出＋手動微調整**: 触針が刃先から落ちる傾きの急変点を刃先として検出し、それより先のデータは除外。数値入力・±ボタン・「刃先確認」グラフのクリックで調整可能
- **Z反転 / Z補正 / 刃先→峰**: 左面（下から測定）の座標系をファイル内の座標変換情報から判定。座標系が反転保存されたファイルは Z 符号を反転、反転されずに保存された逆向き触針ファイルは Z補正 16.036 mm（逆向き触針と上向き触針の高さ基準の差）を自動で加算。測定方向が逆のデータにも対応
- **縦横比**: 1:1（実形状）／厚み方向 ×2〜×20（既定 ×5）／自動
- **表示範囲**: 全体・10mm・5mm・1mm・0.2mm・0.05mm（マウスホイール・ドラッグでも拡大）
- **中心線の水平化**（任意）: 刃先付近の両面近似直線の二等分線が水平になるよう回転
- **厚み表・厚み曲線**: 先端厚さ（距離0）、刃先からの距離ごとの厚みと、0〜距離区間の近似刃角
- **凡例**: 断面グラフの凡例はセットごとに1項目（例: 研磨前・研磨後）。クリックでそのセットの両面をまとめて表示/非表示
- **グラフの表記**: 各グラフの「表記」ボタンで、タイトル・軸の名前・凡例・拡大表示の注記・目盛の数値の表示/非表示、文言、文字サイズ、軸の数値（X/Y の最小・最大・目盛間隔・小数桁。空欄は自動、断面グラフのY軸目盛間隔は既定 0.5mm）を変更（ブラウザに保存）
- **出力**: 断面・厚み曲線の PNG、厚み表 CSV、合成断面データ CSV（指定ピッチで再サンプリング）
- **Z移動・傾き補正（セットごと）**: 断面を上下に平行移動、刃先中心に回転。「自動合わせ」で、刃先から指定区間（既定 3〜20mm）で基準セットと右面・左面が最もよく重なるZ移動量と傾きを最小二乗で計算し、残差（RMS）を表示
- **研磨前後の比較**: 厚み表に基準セット（一番上のセット）との厚みの差 [µm] を表示し、「厚みの変化」グラフで距離ごとの差を表示

## 開発

```
src/core.js   計算ロジック（読込・刃先検出・合成・厚み）
src/app.js    画面処理
src/app.html  画面レイアウト
vendor/       Plotly (MIT License)
```

`node build.mjs` で `hasaki-danmen.html`（単体HTML）を生成します。
